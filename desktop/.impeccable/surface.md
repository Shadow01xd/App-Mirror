# Desktop workspace
Mode: Operate. Build directly in native Slint under the user's delegated composition and pinned Android identity.
## Direction contract
THESIS: Select a connection once, operate all its modes in a persistent desktop workspace.
OWN-WORLD: Android's black, charcoal, yellow, native sans and Material Outlined icons. Brand commitments override the frontend-design stock anchors; Industrial's flat separation informs structure only.
STORY: Identify the single Wi-Fi device, choose a mode, then understand the link direction in one desktop workspace.
FIRST VIEWPORT: 260px connection rail on the left. The disconnected workspace shows the empty state and a real QR. The connected workspace shows the device header, a bounded animated desktop/phone schematic above, then three horizontal mode buttons below. Every button has its icon to the left of its text. No demonstration labels, USB, transfer navigation, advanced selectors, start controls, or phone-service cards in the home view.
FORM: User-pinned left connections / right modes topology, refined as a desktop master-detail workspace. No randomized seed: user has specified the topology and delegated remaining composition.
SIGNATURE: The Android 650ms link reveal reverses for Monitor versus Mirror; 140ms presses and 220ms state transitions honor reduced motion.
FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
